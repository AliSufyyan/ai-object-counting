
# AI Object Counting Using Computer Vision

An image-based computer vision project using pretrained YOLO and OpenCV.

## Current Progress

- [x] Load an image using OpenCV
- [x] Resize the image
- [x] Run pretrained YOLO object detection
- [x] Generate an annotated image with object labels
- [ ] Count detected objects
- [ ] Add class selection and confidence controls
- [ ] Build a Streamlit interface
- [ ] Evaluate counting accuracy

## Technologies

- Python
- Ultralytics YOLO11n
- OpenCV

## Installation

Create and activate a virtual environment, then install dependencies:

```bash
pip install -r requirements.txt
```

## Run

Run the detection script:

```bash
python detect.py
```

Update the command if your Python file has a different name.

## Project Status

Initial image detection is complete. Object counting and the application interface are planned next.
